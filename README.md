# Лабораторна робота №1: Data-Oriented Programming (DOP) у Java

## Опис проєкту
Проєкт демонструє застосування підходу Data-Oriented Programming у сучасній Java (версія 21+) на прикладі системи управління статусами замовлень.

Ключові використані можливості:
* **Sealed Interfaces** (`OrderStatus`) для обмеження ієрархії типів предметної області.
* **Records** (`Pending`, `Paid`, `Shipped`, `Cancelled`) для створення незмінних (immutable) носіїв даних із вбудованою валідацією у компактних конструкторах.
* **Pattern Matching for Switch** та **Record Patterns** у класі `OrderProcessor` для вичерпної обробки всіх станів замовлення без використання гілки `default`.
* **Text Blocks** для читабельного форматування багаторядкового текстового виводу.

## Розрахунок варіанта
* Порядковий номер у списку групи ($N$): **6**
* Формула: $V = N \bmod 3$
* Розрахунок: $V = 6 \bmod 3 = 0$
* **Варіант 0:** Система управління замовленнями (`OrderStatus` / `OrderProcessor`).
